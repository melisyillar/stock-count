# 0002 - Changes reach main through pull requests

## Context

Before pull requests, changes could be added directly to main. This made it difficult to review changes and understand why they were made.

## Decision

Every change must be submitted through a pull request. Another person reviews the changes before they are merged into main.

## Consequences

- Changes are reviewed before they reach main.
- The discussion and reason for each change are recorded.
- Changes take more time because they need review and approval.
